# 🌙 VinoCalc - Math, But Make It Luxury

> Built by a 16 y/o PCM student at 2 AM because normal calculators are boring

**🚀 Live Demo: [Try VinoCalc Here](https://shobhninegi-netizen.github.io/VinoCalc)**
> Note: Agar link na chale to Settings > Pages se activate karna

### Why I Built This:
11th ke Trigonometry + Logs karte waqt normal calc dekh ke neend aa jati thi.  
So I built one with dark wine-glass vibes. Because PCM is tough, UI shouldn't be.

### Features:
- Scientific functions: sin, cos, tan, log, √, x², factorial
- Luxury dark + gold glassmorphism UI
- Fully keyboard supported  
- Built with ZERO libraries - Pure HTML, CSS, JS

### Tech Stack:
HTML5 | CSS3 | Vanilla JavaScript | Git
